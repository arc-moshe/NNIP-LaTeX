The contents of this repository are designed to accompany the NNIP Introduction to LaTeX webinar from May 26, 2026:

Introduction to LaTeX.pptx = the presentation slides
Hello World Code Snippets = the LaTeX code examples used in slides 12-31
Profile Building Step Snippets = the LaTeX code examples, python script, and agency logo used in slides 32-65
Deeper Dive Code Snippets = the LaTeX code examples used in slides 80-96
LaTable = the ado file that makes tables and an accompanying help file
DataHaven Working Example = A full working example presented in slides 108-116, including the data file, table specs, a dofile to generate the profiles, and the profiles themselves
